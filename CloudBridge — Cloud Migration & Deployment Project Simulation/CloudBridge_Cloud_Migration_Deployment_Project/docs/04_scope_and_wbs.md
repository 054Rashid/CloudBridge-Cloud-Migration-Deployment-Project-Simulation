# Scope & WBS

1. **Initiation** — charter, business case, success criteria  
2. **Discovery** — current state, stakeholders, constraints, dependencies  
3. **Design** — target architecture, security, networking, deployment, rollback  
4. **Build** — container, CI, Kubernetes, Terraform, configuration  
5. **Validation** — unit, integration, smoke, performance baseline, UAT  
6. **Cutover** — go/no-go, communication, deployment, validation, rollback  
7. **Handover** — runbooks, support ownership, knowledge transfer  
8. **Closure** — KPI review, lessons learned, action closure

## Definition of Done
Implementation/documentation complete, evidence attached, acceptance criteria met, dependencies cleared and owner confirms completion.
