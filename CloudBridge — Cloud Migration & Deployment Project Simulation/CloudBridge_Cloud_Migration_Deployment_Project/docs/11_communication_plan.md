# Communication Plan

| Audience | Cadence | Format | Purpose |
|---|---|---|---|
| Sponsor | Biweekly | Executive summary | decisions, major risks |
| Core team | Weekly | Working session | progress, blockers |
| Engineering | Twice weekly | Stand-up/async | technical coordination |
| Product | Weekly | Status review | scope, UAT |
| Security | Stage gates | Review | controls/exceptions |
| Operations | Weekly from W10 | Handover review | readiness |
| Business users | UAT/cutover | Briefing | acceptance/change |

Escalation: critical blocker same day; high risk within 24h; scope change before implementation.
