# Project Charter

**Project:** CloudBridge — Cloud Migration & Deployment

**Sponsor:** Northstar Retail (fictional)

**Delivery model:** 16-week simulated enterprise migration

## Objective
Move a Python demand-insights service from a single Ubuntu VM to a repeatable containerized Kubernetes/cloud deployment approach while improving release speed, recovery, environment consistency and operational visibility.

## In scope
Discovery, requirements, target architecture, Dockerization, CI checks, Kubernetes manifests, Terraform target architecture, test/UAT planning, cutover/rollback, stakeholder communication, risk/dependency/change management and operational handover.

## Out of scope
Real customer data, real customer deployment, paid production infrastructure, multi-region DR implementation and post-launch 24/7 support.

## Success criteria
All must-have artifacts complete; automated tests pass; cutover gates met; rollback path documented; no open critical blockers; handover owners assigned.

## Constraints
Self-directed portfolio simulation, no customer access, limited cloud spend, simulated stakeholder responses and a small delivery team.
