# Change Control

1. Log request.  
2. Clarify business reason.  
3. Assess scope, schedule, cost, risk and dependencies.  
4. Identify options.  
5. Obtain decision from accountable owner.  
6. Update baseline.  
7. Communicate.  
8. Track implementation and closure.

| Change | Impact | Disposition |
|---|---|---|
| Add pre-production namespace | +2 days | Approved |
| Add second cloud region | +3–4 weeks / higher cost | Deferred |
| Add handover dashboard | +1 day | Approved |
